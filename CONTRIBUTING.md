# Contributing

Use a branch and a small pull request explaining the behavior change and checks.
Use the dummy emulator workflow in README; never request or use production
credentials or user records. Do not add `.env.local`, service accounts,
database exports, real account fixtures, unlicensed media or deployment metadata.

Run `npm test`, `npm run typecheck` and the relevant emulator checks. Preserve
ownership checks, bearer-token authentication, bounded queries and idempotent
XP awards. Do not move answer keys into client-readable documents or restore
direct student writes to scores. Keep examples and fixtures synthetic.

Contributions to the project code are under its MIT license. Clearly identify
third-party material and preserve its license/attribution. Report security
issues privately using the maintainer's configured channel, not a public issue
containing exploit details or real user data.
