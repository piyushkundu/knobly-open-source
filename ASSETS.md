# Optional assets and external resources

No original binary assets or original Git history are bundled. Course PDFs,
WhatsApp-named photos/screenshots, note scans, diagrams and branding images have
not been given a redistribution license by this export. Do not infer that MIT
licenses those omitted materials. Private Drive download identifiers are removed.

The generic SVG placeholder and simple favicon in `public/sample-assets` are
new code-generated sample assets covered by the package's MIT license. Original
image references are replaced with that placeholder. Course download pages show
an explicit optional-content notice. This is deliberate, not a full media mirror
of a hosted website.

Only add material after documenting its creator, source, license, redistribution
permission and any attribution. Piyush Kundu confirms that the educational text
and code in this source were authored by him. Brand names do not grant trademark
rights or imply an official endorsement of a fork.

Runtime loaders reference external packages/services such as Pyodide, Monaco,
Google Fonts and icon stylesheets. Their bytes are not vendored in this source
archive; they retain their own licenses, terms and network behavior. Dependency
metadata is summarized in `THIRD_PARTY_NOTICES.md`; inspect installed package
licenses and transitive dependencies for a particular built distribution.
